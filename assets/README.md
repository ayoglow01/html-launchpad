# Assets 🎒

Shared files that the lessons, exercises and projects use — plus starter files for your own work.

| Folder | What's inside |
|---|---|
| [images/](images/) | Sample photos in several sizes and formats (`hero-480/800/1200` as JPEG and WebP, a portrait, an avatar, project screenshots); icons (`favicon.ico`, `favicon.svg`, `apple-touch-icon.png`, `icon-192/512.png`); `og-image.jpg` (1200×630, for sharing previews); SVGs (`logo`, `divider`, `sales-chart`); `campus-map.png` for clickable picture areas; `video-poster.jpg` |
| [media/](media/) | `sample-video.mp4`/`.webm`, `sample-audio.mp3`/`.ogg`, and caption files: `captions-en.vtt`, `subtitles-fr.vtt`, `chapters-en.vtt` |
| [templates/](templates/) | Starter files to copy and change |
| [cheatsheets/](cheatsheets/) | One-page summaries and checklists |

## Starter files (templates)

| File | Use it for |
|---|---|
| [boilerplate.html](templates/boilerplate.html) | The smallest correct page |
| [professional-head.html](templates/professional-head.html) | A full, ready-for-real-work `<head>`, with a note on every line (page info, icons, sharing, security, speed hints) |
| [page-skeleton.html](templates/page-skeleton.html) | A whole page: skip link, landmarks, headings, an article, a footer |

## About the media files

Every picture, sound and video here was made for this repo (colour gradients, test patterns, tones), and is shared under the repo's MIT licence. They're stand-ins: swap in real content for real projects, and credit photographers when you use their work.
