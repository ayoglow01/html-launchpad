# html-cracker 🧩

**Learn HTML from zero. One small step at a time.**

HTML is the language every web page is written in. It's not hard. If you can write a shopping list, you can learn HTML.

```html
<h1>Hello!</h1>
<p>This is my first web page.</p>
```

That's real HTML. By the end of this course you'll build and publish your own website. 🌍

---

## Getting started

You need just **2 things**. Both are free.

| | What | Get it |
|---|---|---|
| 1 | A **browser** (you already have one) | [Chrome](https://www.google.com/chrome/) or [Firefox](https://www.mozilla.org/firefox/) |
| 2 | A **code editor** — where you type | [VS Code](https://code.visualstudio.com/) |

### Install VS Code in 3 steps

1. Download VS Code from the link above and install it.
2. Open it. Click the **Extensions** icon on the left (four little squares).
3. Search **Live Server** and click **Install**. It refreshes your page every time you save.

> 💡 **Windows users:** open File Explorer → **View** → **Show** → tick **File name extensions**. Otherwise `index.html` might secretly be `index.html.txt`.

> 📱 **Only have a phone?** Use [CodePen](https://codepen.io/) in your browser for the first lessons.

### Your first page in 5 minutes ⏱

1. Make a folder on your desktop called `my-site`.
2. In VS Code: **File → Open Folder** → choose `my-site`.
3. Make a new file called `index.html`.
4. Type this (typing helps you learn — try not to copy-paste):

   ```html
   <!DOCTYPE html>
   <html lang="en">
   <head>
     <meta charset="UTF-8">
     <meta name="viewport" content="width=device-width, initial-scale=1">
     <title>My first page</title>
   </head>
   <body>
     <h1>Hello, I'm learning HTML!</h1>
     <p>I made this myself.</p>
   </body>
   </html>
   ```

5. Save (**Ctrl + S**, or **Cmd + S** on Mac).
6. Right-click the file → **Open with Live Server**.

🎉 **You just made a web page!** Don't worry about what every line means. [Lesson 2](curriculum/02-html-syntax-and-document-structure/README.md) explains it.

### Get this course on your computer (optional)

On GitHub, click **Code → Download ZIP**, unzip it, and open the folder in VS Code. You can also read everything right here on GitHub.

## How to learn (the secret ✨)

Every lesson, do this:

1. **Read** the short lesson (10–40 minutes).
2. **Type** the examples yourself.
3. **Break** something on purpose and see what happens.
4. **Do** the "🎯 Try it" task.

Little and often beats a lot once. **20 minutes a day is enough.**

## Stuck? 🙋

1. Read the lesson's **⚠️ Careful** box — most surprises are there.
2. Paste your code into the [HTML validator](https://validator.w3.org/nu/). Fix the **first** error first.
3. Search "mdn" + the tag name, e.g. **mdn img**.
4. Ask in the [freeCodeCamp forum](https://forum.freecodecamp.org/) or The Odin Project Discord. Share your code and say what you expected.
