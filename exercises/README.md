# Practice ✏️

Reading helps you *understand*. Practice helps you *remember*. Do a little after every lesson.

| Folder | What's inside | When |
|---|---|---|
| [drills/](drills/) | Short tasks for each lesson. Answers are hidden — click to see them. | Right after each lesson |
| [debug/](debug/) | Broken pages. Find what's wrong and fix it. Answers in [debug/solutions/](debug/solutions/). | When a lesson sends you there |
| [challenges/](challenges/) | Mini-builds: we give you plain text, you turn it into a page. | When a lesson sends you there |

## How to practise

1. Make a folder called `my-work/` for your answers.
2. **Try first, then peek.** Struggling for 2 minutes teaches you more than reading the answer.
3. Check your code in the [validator](https://validator.w3.org/nu/).
4. Different from the answer? That's OK if it still follows the rules. Many tasks have more than one right answer.
