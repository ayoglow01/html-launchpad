# Fix the broken pages 🔧

Every file here is **broken on purpose**. The top of each file says how many problems it has, and which lesson it goes with.

1. Open the file in a browser, and in your editor.
2. Paste the code into the checker at [validator.w3.org/nu](https://validator.w3.org/nu/). But careful: **some bugs are valid HTML** — the wrong tag, bad alt text, broken paths. The checker can't see those. You have to find them yourself.
3. Fix every problem in a copy of the file (for example in a `my-work/` folder).
4. Compare with the explained answers in [solutions/](solutions/README.md).

The automatic checker skips these files on purpose (see `.htmlvalidateignore`).
