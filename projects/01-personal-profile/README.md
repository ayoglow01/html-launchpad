# P1 · Personal profile page

**After:** Lesson 5 · **Time:** 2–4 hours · **Pages:** 1

## What you're making

A one-page profile for yourself (or a made-up developer). Recruiters and classmates should find out who you are, what you're learning, and how to reach you. No CSS needed — the page should work as a well-built document on its own. (Add a little CSS later if you like.)

## What it needs

### Document
- [ ] A full starter page: doctype, `lang`, charset, viewport, a descriptive `<title>` ("Ada Obi — Frontend learner").

### Content
- [ ] One `<h1>` with your name, and a short intro paragraph, with emphasis or importance where it really means something.
- [ ] Sections with `<h2>`: **About**, **Skills**, **Learning journey**, **Favourite resources**, **Contact**.
- [ ] Skills as an unordered list; nested list for sub-skills (e.g. HTML → semantics, forms).
- [ ] Learning journey as an ordered list of milestones with `<time datetime>`.
- [ ] A short description list of 3 terms you've learned and your own definitions.
- [ ] One quotation (`<blockquote>` with `cite` attribute and a `<cite>` for the source title).
- [ ] At least one abbreviation with `<abbr title>`.

### Links
- [ ] A table of contents at the top, with `#` links to each section.
- [ ] Links to at least 3 outside resources, with link text that says where they go. Any that open a new tab say so, and use `rel="noopener"`.
- [ ] Working `mailto:` and `tel:` links.
- [ ] A "Back to top" link.
- [ ] A downloadable CV link (any PDF or the placeholder `files/cv.txt`) using `download`.
