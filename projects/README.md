## How to do a project

1. **Read** the project page from top to bottom.
2. **Sketch** the page on paper: draw boxes and write the tag names inside (`header`, `nav`, `main`…).
3. **Build** it in `my-work/projects/`.
4. **Check** each page in the [validator](https://validator.w3.org/nu/).
5. **Test** using only the keyboard (Tab, Enter, Space).
6. **Score** yourself with the project's "Score yourself" table.
7. **Then** look at the example answer (P1 and P6). Yours can be different and still be right.

## Scoring (same for every project)

| Score | Meaning |
|---|---|
| 0 | Missing or broken |
| 1 | There, but with mistakes |
| 2 | Correct ✅ |
| 3 | Correct, and you can explain why |

You pass when every line scores **2 or more** and the validator shows **no errors**.
