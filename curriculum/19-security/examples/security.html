1. textContent vs innerHTML

Paste this payload, then try both buttons:

<img src=x onerror="document.body.style.background='red'">

With innerHTML the image element is created. The page doesn't turn red only because the CSP blocks inline event handlers — defence in depth. Remove the CSP meta tag and try again.
